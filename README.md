# Lumi links

Served at https://link.get-lumi.com (GitHub Pages; DNS: CNAME link -> lumidevice.github.io at Squarespace). Holds the apple-app-site-association that lets NFC taps (/tap/<id>) and friend invites (/friend/<code>) open the Lumi app. The old host xavierpuchert.github.io keeps the same file until every Lumi writes this host to its tag.
